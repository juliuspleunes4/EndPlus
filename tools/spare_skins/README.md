# Spare skins

Unused assets kept for future mobs.

- `quadruped_predator.png` (64x32) + `quadruped_predator_skin.js` (generator: `node quadruped_predator_skin.js out.png`)
  and `QuadrupedPredatorModel.java.txt` (the matching cat/wolf-shaped model, 4 legs + tail + head spikes).
  This was the first Void Stalker design before it became a humanoid. Intended for a quadruped mob,
  e.g. the Prism Crawler or Cliff Wraith. Rename the model class/layer when reusing.
